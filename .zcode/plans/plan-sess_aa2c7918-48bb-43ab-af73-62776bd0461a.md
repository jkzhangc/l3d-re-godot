## 目标
把死亡黑屏的两个时间参数（黑屏淡入时长、全黑等待时长）从 `player.gd` 的局部 `@export` 迁到 `Global` autoload 单例，作为全局可配置项，与现有 `Global.death_music_path` 等死亡配置集中管理。

## 改动清单

### 1. `script/global.gd` — 新增两个全局 @export
把第 85–88 行的「死亡音乐接口」段扩展为「死亡处理」段，在 `death_music_path` 之后新增：
```gdscript
# ═══════════════════════════════════════
# 死亡处理
# ═══════════════════════════════════════
@export var death_music_path: String = "res://sound/残念なお知らせ.wav"  ## 死亡音乐文件路径
@export var death_fade_duration: float = 2.0  ## 死亡黑屏淡入时长（秒）
@export var death_black_hold: float = 1.0     ## 死亡全黑后等待时长（秒）
```
默认值沿用 player.gd 现值（2.0 / 1.0），行为零变化。

### 2. `script/player.gd` — 删局部声明，改读 Global
- **删除**第 47–49 行的 `@export_group("死亡")` + 两个 `@export var death_fade_duration / death_black_hold`（46 行「死亡」注释段保留）。
- **改第 364 行**：`death_fade_duration` → `Global.death_fade_duration`
- **改第 374 行**：`death_black_hold` → `Global.death_black_hold`

### 3. `AGENTS.md` — 更新文档（CLAUDE.md 不再维护）
- 在「快速参考」的「全局单例」条目补一句：Global 还含死亡黑屏时间参数（`death_fade_duration` / `death_black_hold`）。
- 在「当前状态」表的「死亡系统」行备注：黑屏时长可在 Global 单例配置。

## 风险评估
- ✅ 已确认两个变量无 `.tscn`/`.tres` 覆盖，删除安全。
- ✅ Global 是已注册 autoload，player.gd 已有 `Global.death_music_path` 引用先例，引用方式一致。

- ⚠️ 唯一行为差异：配置入口从「player 节点 Inspector」改为「Global 单例 Inspector」——这正是「全局设置」的预期效果。
