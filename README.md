# のび太的求生之路 — l3d-re-godot

**野比大雄的生化危机 L4D2 同人游戏**，使用 **Godot 4.6** 重制的俯视角 2D 像素风格动作游戏。

力求还原 Left 4 Dead 2 的核心机制与游戏体验 — 武器系统、敌人 AI、导演系统、物品拾取、生存合作。

## 开发状态

🚧 **核心战斗循环搭建阶段** — 基础玩法框架已完成，内容填充中。

## 技术栈

- **引擎**：Godot 4.6
- **语言**：GDScript
- **物理**：Jolt Physics
- **渲染**：Mobile 渲染器（Direct3D 12）
- **分辨率**：640×480（设计基准）
- **素材格式**：RPG Maker VX Ace 图块（32×32px）+ 角色精灵表

## 快速开始

### 环境要求

- [Godot 4.6](https://godotengine.org/)（标准版，无需 .NET）

### 运行

```bash
# 在编辑器中打开项目
godot --editor

# 直接运行游戏
godot

# 运行主场景
godot scene/main.tscn
```

### 操作

| 按键 | 功能 |
|------|------|
| 方向键 / WASD | 移动 |
| 空格 / Z | 确定 / 攻击 |
| X / Esc | 主菜单 |
| Shift | 跑步 |
| Tab | 调试可视化切换 |
| 1–5 | 快捷栏槽位 |
