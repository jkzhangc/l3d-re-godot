# のび太的求生之路 — l3d-re-godot

**野比大雄的生化危机 L3D 〜LEFT 3 DEAD〜 重制**，使用 **Godot 4.6** 的俯视角 2D 像素风格动作游戏。当前版本 **v0.34**。

> **设计方向（2026-09 定稿）**：**L3D 混合路线** —— 保留 L4D 式战役/Rush/导演框架，战斗核心采用 L3D 的**见切→反击→背刺即死**循环与"角色=打法"差异化。敌人阵容、角色深度、武器系统等决策见 [游戏设计方向-L3D混合](游戏设计方向-L3D混合.md)（与其他文档冲突时以该文档为准）。

力求还原 L3D 的核心机制与游戏体验 — 见切反击战斗、Rush 尸潮、导演系统、物品拾取、生存合作。

## 开发状态

🚧 **核心战斗循环与局域网合作模式并行开发中**。单机战斗核心已基本对齐原作（见切/反击/背刺必杀/Guts/Heat/属性/Rush 三型/敌人阵容均已落地）；完整战役（第二战役未做）、剩余 Boss、成就之外的纵深内容仍在完善。

> 当前缺口以 [原作L3D缺失功能清单](原作L3D缺失功能清单.md)（2026-10-02 逐项 grep 代码核实）为**唯一有效清单**。

## 已实现功能

### 核心玩法

| 系统 | 说明 |
|------|------|
| **玩家角色** | 4 名可玩角色（のび太 / ジャイアン / スネ夫 / 源静香），`CharacterData` 驱动外观/HP/TP/音效/武器限制；外观与武器行走图 JSON 化配置 |
| **状态机** | 待机 / 行走 / 跑步 / 各武器举起与攻击 / 装填 / 推击 / 投掷 / 见切反击等；新增武器需在 `player.tscn` 建同名状态节点 |
| **见切→反击** | 敌人命中瞬间 0.3s 窗口内按攻击键 → 无伤 + 自动反击（punch/heavy/issen 随角色不同），必带超 Push 推开敌群；输入间隔 0.7s |
| **背刺（必杀）** | 敌我朝向同向（`BACKSTAB_FACING_DOT=0.7`）或敌人未察觉 → 非 Boss 即死、Boss ×1.5；免疫只认 `tank_enemies` 组 |
| **Guts 保底** | HP≥2 时任何攻击最低保留 1 HP（Heat 中停止） |
| **Heat / 削り** | Hunter 系首狩り命中附带 Heat（封锁见切/换人）+ 武器削损；γ 丸呑み多段削损 |
| **属性系统** | 炎/雷/氷/酸 + 敌人抗性（炎=燃烧 DoT、雷=感电硬直、氷=冻结+受击 ×1.5） |
| **TP / SA / 觉醒** | 角色 TP（`PlayerState.set_tp()` 唯一入口）+ 专属 SA（感覚向上 / リサイタル / バックパック / しゃがみ回避）+ 觉醒（大雄集中射击） |

### 局域网联机（开发中）

> **Host 权威**模型：Client 只提交输入和操作意图，Host 唯一结算移动、战斗、AI、资源、拾取与流程。仍在开发与回归测试中，不能视为完整合作战役。

| 已接入能力 | 说明 |
|------|------|
| **连接与大厅** | ENet 建房/加入、`hello → hello_ack` 握手、玩家列表、选角、Host 开始游戏；默认端口 `27015`（大厅可改）|
| **UPnP** | 建主时可自动映射 UDP 端口并展示公网直连地址（不内置打洞/房间发现；公网需路由器映射或 frp/樱花等 UDP 穿透）|
| **跨场景会话** | `Net` 常驻管理会话；scene-ready ACK/flush 协议降低切图竞态 |
| **权威玩法同步** | Host 模拟玩家移动、枪械/装填/推击/投掷、敌人、子弹、安全门、章节确认；资源走固定白名单（`NETWORK_WEAPONS`/`THROWABLES`/`SPECIALS`），RPC 只传 id |
| **实体与快照** | Spawn/Despawn/掉落/流程走 reliable RPC；位置高频状态走 `unreliable_ordered` 快照 + 插值缓冲 + 客户端本地预测 + 2s 可靠重同步软并流；不依赖 `MultiplayerSpawner`/`Synchronizer` |
| **表现同步** | 敌人死亡可靠广播（不围尸）、掉落物、爆炸/火海/闪光、BGM、头顶 1P/2P 名牌与 HP 条 |
| **倒地/救援/团灭** | 多人倒地/救援、全员非站立 Host 统一黑屏重载、真死亡下一章满血归队 |
| **自动回归** | `tools/net_regression.py`：Host/Client 无头双进程，覆盖握手/选角/移动/战斗/掉落/投掷物/安全门/倒地救援/团灭等场景 |

**当前边界**：死亡观战镜头、断线重连、房间发现、公网安全、主机迁移、Host 存档恢复、完整多人长流程压力测试未完成。详细协议见 [联机系统架构设计](联机系统架构设计.md)。

## 技术栈

- **引擎**：Godot 4.6
- **语言**：GDScript
- **物理**：Jolt Physics
- **渲染**：Mobile 渲染器（Direct3D 12）
- **分辨率**：1280×960（可视 640×480，zoom 2x；设计基准）
- **素材格式**：RPG Maker VX Ace 图块（32×32px）+ 角色精灵表

## 快速开始

### 环境要求

- [Godot 4.6](https://godotengine.org/)（标准版，无需 .NET）

### 运行

```bash
# 在编辑器中打开项目
godot --editor

# 直接运行游戏
godot

# 运行主场景
godot scene/main.tscn

# 无头检查（CI）
godot --headless --quit
```

### 局域网联机测试

1. 在标题画面选择"联机游戏"。
2. Host 创建房间（可勾选 UPnP 自动端口映射）；Client 填写 Host 的 IPv4 地址并加入（本机双开用 `127.0.0.1`）。
3. 端口在大厅 **端口框** 设置（默认 `27015`），建主与加入需一致。
4. 等待握手和角色选择完成后，由 Host 点击"开始游戏"。
5. 跨设备连接时，确认 Host 防火墙放行所选 **UDP 端口**。

**内网穿透**：联机走 ENet（UDP），连接目标就是 `IP:UDP端口` ——
- Tailscale / ZeroTier 等虚拟局域网：直接填虚拟 IP，端口保持默认；
- frp / 樱花frp 等端口映射型穿透：隧道类型必须为 **UDP**（纯 TCP 隧道不可用），Client 填穿透服务给的远程 IP + 远程端口。
- 游戏内置 **UPnP 自动端口映射**（路由器支持时可用）；无打洞 / 房间发现，公网直连需路由器端口映射或上述穿透方案。

### 操作

按键绑定以 `project.godot` 的 `[input]` 段为准。详细图文见游戏内"操作说明"（`操作说明.txt`，运行时资源）。**注意：移动只绑定了方向键，WASD 未绑定**（A/S/D/C/E 另有用途）。

| 按键 | 输入动作 | 功能 |
|------|----------|------|
| 方向键 | `左`/`右`/`上`/`下` | 移动 / 菜单选择 |
| Ctrl | `行走键` | 按住 = 慢走（默认跑步） |
| Z | `确定键` | 攻击 / 确认；**见切也用它**（敌人命中瞬间按） |
| X / Esc | `取消键` | 取消 / 返回；武器举起或攻击时按住 = 固定朝向 |
| P / Esc | `菜单键` | 打开/关闭菜单 |
| D | `功能键` | 互动：拾取 / 换武器 / 医疗箱 / 防守战机器 / **救援倒地队友** |
| Shift | `举起放下武器键` | 举起 / 放下武器 |
| A | `装填键` | 装填；投掷物瞄准时 = 投掷加格键（调远） |
| S | `推击键` | 近战推击（万能打断）；投掷物瞄准时 = 投掷减格键（调近） |
| C | `SA键` | 释放角色 SA 特殊技 |
| 空格 | `覚醒键` | 发动觉醒（如大雄的集中射击） |
| 1 / 2 | `主武器键` / `副武器键` | 切换主 / 副武器 |
| 3 / 4 / 5 | `治疗品键` / `辅助品键` / `投掷物键` | 使用治疗品 / 辅助品 / 举起-放下投掷物 |
| E | `丢弃武器键` | 把手上的武器全部丢到地上 |
| Q | `切换角色键` | 循环切换队员（**联机禁用**） |
| Ctrl+1/2/3 | `选择队员1键`~`选择队员3键` | 直接选队员（**联机禁用**） |
| F1 | — | 查看更新日志（首次进游戏自动显示一次） |
| Tab | `调试可视化键` | 切换调试可视化（碰撞体/血条/寻路/爆炸环） |

> 移动端：屏幕左下摇杆 + 右下动作/物品/系统三区按钮，功能与键盘一致；布局可在"设置 → 按键布局"拖动或隐藏。

## 开发命令

```bash
# 调试运行
godot --editor --debug

# 无头检查（CI）
godot --headless --quit

# 导出项目
godot --headless --export-release "Windows Desktop" build/game.exe

# 一步到位：导出 Windows 版 → 压成 zip（发布用）
python tools/package_release.py

# 联机无头回归（Host/Client 双进程）
python tools/net_regression.py
```

> ⚠️ 导出前必须关闭 Godot 编辑器；**绝不能**把 `*.import` / `*.remap` / `*.uid` 加进 `exclude_filter`（会导致 UID 引用集体错位，只有导出包会炸）。详见 [CLAUDE.md](CLAUDE.md)。
