# のび太的求生之路 — l3d-re-godot

**野比大雄的生化危机 L4D2 同人游戏**，使用 **Godot 4.6.3** 重制的俯视角 2D 像素风格动作游戏。

力求还原 Left 4 Dead 2 的核心机制与游戏体验 — 武器系统、敌人 AI、导演系统、联机合作、物品拾取。

## 开发状态

🚧 **核心战斗循环搭建阶段** — 基础玩法框架 + 联机同步已完成，内容填充中。

---

## 已实现功能

### 核心玩法

| 系统 | 说明 |
|------|------|
| **玩家角色** | 完整状态机（待机 / 行走 / 跑步 / 手枪 / 小刀 / 霰弹枪 / 步枪 / 冲锋枪）；外观/HP/音效由 CharacterData 驱动 |
| **武器系统** | 手枪 / 小刀 / 霰弹枪 / 步枪 / 冲锋枪；举起/放下动画 + 攻击 + 弹夹/备弹 + 装填 + 拾取/替换/掉落 |
| **武器槽位** | WeaponSlot 枚举（PRIMARY 主武器 / SECONDARY 副武器），每槽位独立管理 |
| **射击模式** | FireMode：TAP 点按单发 / HOLD 按住连发（步枪/冲锋枪） |
| **子弹系统** | Node2D + Sprite2D + Area2D；BulletData 数据驱动（弹道/散射角/穿透/击退/硬直）；碰撞矩形随方向旋转；发射者排除 + 目标永久去重 + 尸体穿透 |
| **近战系统** | 小刀攻击，Area2D hitbox 判定 + 实例级去重 |
| **装填系统** | NORMAL 模式（一次装满）+ SHOTGUN 模式（逐发循环 + 结束上膛）；动画 + 音效 + 朝向锁定；装填期间可移动 |
| **攻击后动画** | 攻击帧播完后可选播放 post_attack 动画 + 音效，再切回武器举起 |
| **空弹机制** | 弹夹为空时播放空弹音效，不发射子弹 |

### 敌人 AI

| 系统 | 说明 |
|------|------|
| **状态机** | 待机 / 发现（"！"提示）/ 追击 / 攻击 / 击退 / 硬直 / 死亡 / 爆头死亡 |
| **A\* 寻路** | TileMapLayer 格子可通行性 + 四方向搜索 + 共线平滑 + 推离墙壁；static 地图缓存全图共享；降级模式（失败→直接追击滑墙）；实体障碍（敌人互绕） |
| **攻击判定** | 双矩形系统（触发矩形 + 命中矩形），统一投影法检测，随敌人朝向旋转 |
| **受击系统** | HurtArea 碰撞体（层5）；击退（沿子弹方向推开 + 硬直）+ 硬直（原地冻结）；暴击率判定 + 爆头死亡 |
| **伤害去重** | 三层防护：子弹侧永久去重 + 目标侧源头去重（1秒窗口）+ 近战实例去重 |

### 联机系统

| 系统 | 说明 |
|------|------|
| **大厅** | 创建房间 / 加入房间 / 返回主菜单；IP + 端口直连 |
| **主机权威** | Host 端权威架构 — 攻击/装填/敌人状态由 Host 判定并广播 |
| **位置同步** | @rpc 手动同步位置/朝向（20Hz）；镜头跟随本地玩家 |
| **战斗同步** | 攻击特效/音效/子弹广播到第三方；弹药同步（弹夹 + 备弹）；敌人状态 + HP + Attack 动画广播 |
| **角色同步** | Puppet 动画驱动 — 举起/放下/攻击动画本地驱动（帧序列反向播放）；行走动画同步；武器外观同步 |
| **HUD 队友** | 队友血条（名字 + HP 血条 + 数值）；authority 匹配显示 |
| **敌人 Puppet** | Client 端敌人 puppet 攻击动画驱动；HP 同步时自动销毁穿透子弹 |

### 角色切换系统

| 系统 | 说明 |
|------|------|
| **队伍系统** | `Global.team: Array[Dictionary]`，独立 HP/装备/弹药/位置 |
| **切换操作** | Q 循环切换角色 / Ctrl+1/2/3 直选队员；0.5s 冷却 |
| **队友精灵** | TeammateStandin（Node2D+Sprite2D），挂在 DecorLayer |
| **武器行走图** | `CharacterData.weapon_walk_textures`，回退 WeaponData 兜底 |
| **武器限制** | `allowed_primary/secondary_weapons`（item_id 白名单） |
| **死亡切换** | HP=0 自动切存活队员，全灭才走死亡流程 |

### 导演系统

| 系统 | 说明 |
|------|------|
| **导演总控** | `Director` autoload — 全局节奏管理 |
| **紧张度** | 五因子（HP/弹药/距离/进度/战斗）实时计算 |
| **节奏控制** | Build-up → Peak → Cooldown 三阶段循环 |
| **生成管理** | 散兵定时生成 + 尸潮分批生成 |
| **事件编排** | 自然尸潮 + 剧本事件（Crescendo） |
| **物品投放** | HP<50% / 弹药<30% 自动决策投放 |
| **安全门/传送点** | SafeDoor / TeleportPoint + 踏步动画过渡 |

### HUD / UI

| 系统 | 说明 |
|------|------|
| **战斗 HUD** | CanvasLayer — HP 血条（左上，`ＨＰバー.png` 外框 + `ＨＰメーター.png` 填充，低血量变红）+ 5 槽位竖排快捷栏（右侧垂直居中）；可见性总/分开关；队友血条（联机） |
| **快捷栏** | 槽位 1/2 = 主/副武器（名称 + 弹夹 + 备弹）；槽位 3/4/5 = 治疗/辅助/投掷品（名称 + 数量） |
| **伤害数字** | DamageNumber 渐变上浮弹出；GradientLabel 渲染；9 种缓动 + 粗体/阴影 + 颜色可配；CanvasLayer 层叠 |
| **标题画面** | RM2K3 风格窗口 + 光标动画 + 20 色表采样 + 粗体/描边/阴影 + 纵向渐变 |
| **主菜单** | 物品/装备双面板 + 存档 + 退出 + 设置（音量/朝向模式）+ 联机入口 |

### 物品与拾取

| 系统 | 说明 |
|------|------|
| **武器拾取物** | 地图放置；自动拾取（空槽位）/ 长按替换（1.2s，金色圆环进度指示器）；替换时旧武器掉落地面（含弹夹+备弹转移） |
| **物品系统** | 治疗/弹药/投掷品，ItemData 资源驱动，背包计数 |
| **拾取踏步动画** | 地面武器精灵表动画（帧序列 + 时长可配） |

### 系统功能

| 系统 | 说明 |
|------|------|
| **菜单流程** | 标题画面 → 战役选择 → 角色选择(1-3人) → 难度选择 → 联机/单机 → 加载安全屋 |
| **存档系统** | JSON 存档 + checkpoint + L4D2 风格死亡重载 |
| **死亡系统** | 死亡精灵 + 渐黑遮罩（CanvasLayer）+ 自动重载存档；黑屏时长/音乐音量 Global 可配 |
| **相机跟随** | 平滑跟随玩家 + 基于 TileMapLayer tile 范围的边界限制；联机模式自动查找本地玩家 |
| **音频系统** | SFX / Music 独立总线；音量 0–100% 可调；音效并发限制（同音效最多 3 实例） |
| **设置系统** | 音乐/音效音量 + 固定朝向模式（切换式/按住式）；保存到 config.json |
| **固定朝向** | 武器举起/攻击状态下锁定朝向；切换式=按取消键锁/解锁，按住式=按住锁定 |
| **文字渲染** | 方舟像素字体 (Ark Pixel) 12/16px monospaced；GradientLabel 统一接口；CPU 预渲染纵向渐变 + Label shader 纯色双路径；粗体/阴影/描边；色表缓存 |
| **动画特效** | VXAnimSprite 系统 — VX Ace 精灵表播放（多精灵/偏移/混合模式/跟随目标）；VX Anim Editor 可视化编辑器 |
| **地图编辑** | VXTileMap 插件 — VX Ace 自动图块节点 + VXGridEditor 底部面板；TileSet 生成器；A4 图块转换器 |
| **调试可视化** | TAB 键切换 — 碰撞体/血条/受击碰撞体/子弹/攻击判定/寻路路径 + 网格 |

## 技术栈

- **引擎**：Godot 4.6.3
- **语言**：GDScript
- **物理**：Jolt Physics
- **渲染**：Mobile 渲染器（Direct3D 12）
- **分辨率**：1280×960（设计基准）
- **素材格式**：RPG Maker VX Ace 图块（32×32px）+ 角色精灵表
- **字体**：方舟像素字体 (Ark Pixel) 12px/16px monospaced 中文

## 快速开始

### 环境要求

- [Godot 4.6.3](https://godotengine.org/)（标准版，无需 .NET）

### 运行

```bash
# 在编辑器中打开项目
godot --editor

# 直接运行游戏
godot

# 运行主场景
godot scene/main.tscn
```

### 操作

| 按键 | 功能 |
|------|------|
| 方向键 / WASD | 移动 |
| 空格 / Z | 确定 / 攻击 |
| X / Esc | 主菜单 |
| Ctrl | 行走（默认跑步） |
| **Tab** | 调试可视化切换（碰撞体/血条/寻路/路径/网格） |
| **Q** | 循环切换角色 |
| **Ctrl+1/2/3** | 直选队员 |
| 取消键 | 固定朝向（武器举起/攻击时） |
| 1–5 | 快捷栏槽位切换 |
