# のび太的求生之路 — l3d-re-godot

**野比大雄的生化危机 L3D 〜LEFT 3 DEAD〜 重制**，使用 **Godot 4.6** 的俯视角 2D 像素风格动作游戏。

> **设计方向（2026-09 定稿）**：**L3D 混合路线** —— 保留 L4D 式战役/Rush/导演框架，战斗核心采用 L3D 的**见切→反击→背刺即死**循环与"角色=打法"差异化。敌人阵容、角色深度、武器系统等决策见 [游戏设计方向-L3D混合](游戏设计方向-L3D混合.md)（与其他文档冲突时以该文档为准）。

力求还原 L3D 的核心机制与游戏体验 — 见切反击战斗、Rush 尸潮、导演系统、物品拾取、生存合作。

## 开发状态

🚧 **核心战斗循环与局域网合作模式并行开发中** — 单人基础玩法、Director Phase 1–3、Host 权威联机主干与多人倒地/救援/团灭恢复均已落地；完整战役流程、特殊感染者与公网能力仍在持续完善。

### 局域网联机（开发中）

> 当前采用 **Host 权威** 模型：Client 只提交输入和操作意图，Host 唯一结算移动、战斗、AI、资源、拾取与流程；联机功能仍在开发和回归测试中，不能视为完整合作战役。

| 已接入能力 | 说明 |
|------|------|
| **连接与大厅** | ENet 建房/加入、`hello → hello_ack` 握手、玩家列表、角色选择、Host 开始游戏与断开清理；默认端口 `27015`（大厅端口框可改，支持 UDP 型内网穿透端口） |
| **跨场景会话** | `NetworkManager` 常驻管理会话与 `PlayerState`；通过 scene-ready ACK/flush 协议降低切图竞态风险 |
| **权威玩法同步** | Host 模拟玩家移动、枪械/装填/近战推击、敌人、子弹、投掷物、安全门和章节确认；Client 应用 Host 下发的结果 |
| **实体与快照** | Spawn/Despawn、拾取和流程事件走 reliable RPC；位置等高频状态走 `unreliable_ordered` 快照；不依赖 `MultiplayerSpawner` / `MultiplayerSynchronizer` |
| **拾取与库存** | 武器、治疗品与投掷物均由 Host 校验距离、归属和库存后提交；已修复 Client 无法请求拾取投掷物的问题 |
| **倒地/救援/团灭** | HP=0 先倒地（躺地 + 缓慢爬行 + 流血池约 20s，头顶显示救援进度环），队友按住确定键 3s 救起（30% HP）；流血耗尽转真死亡；全员非站立时 Host 统一黑屏重载本章，真死亡玩家在下一章开头满血归队 |
| **自动回归** | 已提供 Host/Client 无头双进程测试入口，覆盖握手、选角、移动、战斗/掉落物、投掷物拾取、安全门、倒地/救援与团灭重载等场景 |

**当前边界**：死亡观战镜头、断线重连、房间发现/NAT 穿透、公网安全、主机迁移、Host 存档恢复，以及完整多人长流程压力测试仍未完成。详细协议与阶段状态见 `联机系统架构设计.md`。

## 快速开始

### 环境要求

- [Godot 4.6](https://godotengine.org/)（标准版，无需 .NET）

### 运行

```bash
# 在编辑器中打开项目
godot --editor

# 直接运行游戏
godot

# 运行主场景
godot scene/main.tscn
```

### 局域网联机测试

1. 在标题画面选择“联机游戏”。
2. Host 创建房间；Client 填写 Host 的局域网 IPv4 地址并加入（本机双开可使用 `127.0.0.1`）。
3. 端口在大厅 **端口框** 中设置（默认 `27015`），建主与加入需一致。
4. 等待握手和角色选择完成后，由 Host 点击“开始游戏”。
5. 跨设备连接时，确认 Host 防火墙放行所选的 **UDP 端口**。

**内网穿透**：联机走 ENet（UDP），连接目标就是 `IP:UDP端口` —
- Tailscale / ZeroTier 等虚拟局域网：直接填虚拟 IP，端口保持默认；
- frp / 樱花frp 等端口映射型穿透：隧道类型必须为 **UDP**（纯 TCP 隧道不可用），Client 填穿透服务给的远程 IP + 远程端口，Host 侧端口填隧道指向本机的本地端口；
- 游戏暂无内置 UPnP / 打洞 / 房间发现，公网直连需路由器端口映射或上述穿透方案。

### 操作

按键绑定以 `project.godot` 的 `[input]` 段为准。**注意：移动只绑定了方向键，WASD 未绑定**（W 未使用，A/S/D 已分配给装填/推击/技能）。

| 按键 | 输入动作 | 功能 |
|------|----------|------|
| 方向键 | `左`/`右`/`上`/`下` | 移动 |
| Z / 空格 | `确定键` | 确定 / 攻击 |
| X | `取消键` | 取消；武器举起或攻击时按住 = 固定朝向 |
| Esc | `取消键` + `菜单键` | 打开/关闭菜单（同时命中两个动作） |
| P | `菜单键` | 打开菜单 |
| Ctrl | `行走键` | 按住 = 行走（默认为跑步） |
| Shift | `举起放下武器键` | 举起 / 放下武器 |
| A | `装填键` | 装填；投掷状态下复用为 `投掷加格键` |
| S | `推击键` | 近战推击；投掷状态下复用为 `投掷减格键` |
| D | `技能键` | 按住后配合触发键搓招释放技能 |
| 1 / 2 | `主武器键` / `副武器键` | 切换主 / 副武器 |
| 3 | `治疗品键` | 使用治疗品 |
| 4 | `辅助品键` | 使用辅助品 |
| 5 | `投掷物键` | 使用投掷物 |
| Q | `切换角色键` | 循环切换队员 |
| Ctrl+1~4 | `选择队员1键`~`选择队员4键` | 直接选队员 |
| Enter | `开始游戏键` | 标题画面开始 |
| Tab | `调试可视化键` | 切换调试可视化（碰撞体/血条/寻路） |
