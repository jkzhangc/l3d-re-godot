## 核心概念

VX Ace 图块（32×32 PNG）→ Godot TileSet（.tres）→ TileMapLayer → 可绘制地图

| 步骤 | 工具 | 产物 |
|------|------|------|
| 1. 浏览 & 测试图块 | scene/map_editor.tscn（运行时） | 确认 tile 坐标 |
| 2. 保存 TileSet | 编辑器顶栏 [保存.tres] | object/xxx.tres |
| 3. 配置图块属性 | Godot 编辑器（双击 .tres） | 碰撞/导航/地形 |
| 4. 在其他场景使用 | TileMapLayer.tile_set | 最终地图 |

═══════════════════════════════════════════════════════════

一、运行时编辑器：浏览 & 测试图块

═══════════════════════════════════════════════════════════

1. 打开 scene/map_editor.tscn → 运行

2. 点顶栏 [加载...] → 弹出图块浏览器
   - 自动扫描 art/Tilesets/ 下所有 PNG
   - 左侧列表点击文件名 → 右侧显示完整预览
   - 底部显示尺寸和 tile 数量（如 256×512 | 8×16 tiles）

3. 点 [加载选中图块] → 左侧调色板显示所有 tile
   - 点击调色板中的 tile 来选中（黄色高亮）
   - 滚轮缩放调色板

4. 在地图上绘制：
   - 左键点击地图 → 放置选中的图块
   - 右键点击地图 → 擦除图块
   - 滚轮缩放地图 | 中键拖拽 | WASD 平移

5. 顶栏 [地面层] / [装饰层] 切换图层
   - 地面层（底层）：A5 类图块，如草地、路面、水面
   - 装饰层（上层）：B~E 类图块，如建筑、树木、家具（开启 y_sort）

6. 点 [清除] 清空当前图层

═══════════════════════════════════════════════════════════

二、保存为 .tres

═══════════════════════════════════════════════════════════

1. 确认已加载图块素材（调色板有内容）

2. 点顶栏 [保存.tres] → 弹出保存对话框

3. 命名规则建议：
   - A5 地面类：  outside_ground.tres / dungeon_floor.tres / school_ground.tres
   - B~E 装饰类： outside_decor.tres  / dungeon_walls.tres / school_furniture.tres
   - A1~A4 自动图块：outside_autotile.tres / forest_autotile.tres

4. 保存到 object/ 目录

三、配置图块属性（Godot 编辑器内）

═══════════════════════════════════════════════════════════

在 Godot 文件系统面板中双击 .tres 文件，底部出现 TileSet 编辑器：

┌──────────────────────────────────────────┐
│  [Atlas] [Physics] [Navigation] [Terrains] │  ← 四个标签
├──────────────────────────────────────────┤
│                                           │
│    图块预览区（Atlas 视图）                │
│                                           │
├──────────────────────────────────────────┤
│  属性/工具面板（根据当前标签不同而变化）     │
└──────────────────────────────────────────┘

--- 3a. Physics（碰撞）---

用途：让墙壁、栅栏、树桩等 tile 阻挡角色移动。

操作：
1. 切换到 Physics 标签
2. 确认选中 Physics Layer 0（默认）
3. 在 Atlas 里点选一个需要碰撞的 tile（如墙壁块）
4. 在 Physics 面板点击 + 添加碰撞形状
5. 选择 Rectangle（矩形）或 Polygon（多边形）
6. 在 tile 上拖拽绘制碰撞区域
7. 重复为其他需要碰撞的 tile 添加
8. 保存 .tres（Ctrl+S）

注意：
- 如果使用 GodotPhysics：项目设置 → Physics → 2D
- 如果使用 Jolt（本项目）：Jolt Physics 支持 2D 碰撞
- TileMapLayer 默认使用 PhysicsLayer 0

--- 3b. Navigation（导航）---

用途：标记 AI 角色可以行走的区域（需要 NavigationServer2D）。

操作：
1. 切换到 Navigation 标签
2. 确认选中 Navigation Layer 0
3. 在 Atlas 里点选可通行的地面 tile
4. 在 Navigation 面板 + 添加导航多边形
5. 绘制覆盖整个 tile 的矩形导航区
6. 保存 .tres

使用前提：场景中要有 NavigationRegion2D 或 NavigationServer2D 相关节点。

--- 3c. Terrains（地形/自动图块）---

这是 VX Ace 自动图块（A1~A4）的 Godot 等价实现。
用途：自动根据相邻 tile 选择正确的边角图块。

概念对照：

  VX Ace                      Godot TileSet
  ─────────                   ─────────────
  自动图块（Autotile）    ←→  Terrain（地形）
  自动画出边框/转角       ←→  Bitmask 自动匹配
  A2 草地 → 泥地过渡     ←→  不同 terrain 之间的连接规则

操作：
1. 切换到 Terrains 标签
2. 点 + 添加 Terrain（如 "草地"、"水面"、"墙壁"、"路面"）
3. 给每个 Terrain 设置颜色（建议：草地=绿、水面=蓝、墙壁=灰）
4. 在 Atlas 里选中每个 tile，设置 Terrain Bitmask

Bitmask 规则：
    bit 0 (1)   = 上边有连接
    bit 1 (2)   = 右边有连接
    bit 2 (4)   = 下边有连接
    bit 3 (8)   = 左边有连接
    bit 4 (16)  = 右上角内部
    bit 5 (32)  = 右下角内部
    bit 6 (64)  = 左下角内部
    bit 7 (128) = 左上角内部

常用 bitmask 示例（3×3 自动图块）：

    全封闭（中间块）:        水平边:
    ████████                ────────
    ████████   bit = 255    ████████   bit = 255
    ████████                ────────

    上边:                    左上角:
    ────────                ┌───────
    ████████   bit = 1+2+4  │██████   bit = 1+8+...
    ████████                ████████

5. 全部设置完后保存 .tres
6. 在 TileMapLayer 中切换到 Terrain 绘制模式:
   - TileMap 面板顶部选 "Terrain"（而非 "Tile"）
   - 选择一个 Terrain 开始画
   - Godot 自动根据相邻 tile 选择正确的边角图块

四、在其他场景中使用 .tres

═══════════════════════════════════════════════════════════

方式 A：编辑器手动绘制

1. 新建场景（Node2D 为根节点）
2. 添加 TileMapLayer 节点 → 命名为 GroundLayer
3. 在检查器的 TileSet 属性 → 加载 object/xxx.tres
4. 底部出现 TileMap 面板 → 选 tile → 直接在场景中点击放置
5. 再添加另一个 TileMapLayer → 命名为 DecorLayer
   - y_sort_enabled = true（上层需要 Y 排序）
   - 加载装饰类 .tres
6. 添加 Camera2D

典型场景结构：
  MapScene (Node2D)
  ├── GroundLayer (TileMapLayer)
  │   tile_set = res://object/outside_ground.tres
  ├── DecorLayer (TileMapLayer)
  │   tile_set = res://object/outside_decor.tres
  │   y_sort_enabled = true
  └── Camera2D
      position = Vector2(480, 320)

方式 B：脚本程序化放置

  extends Node2D

  @onready var ground: TileMapLayer = $GroundLayer
  @onready var decor: TileMapLayer = $DecorLayer

  func _ready():
      # 填充地面（8×16 的 A5 tileset，第三行是草地）
      for y in 20:
          for x in 30:
              var tile_x := randi() % 4 + 2   # 列 2~5（草地变体）
              var tile_y := randi() % 2 + 2   # 行 2~3
              ground.set_cell(Vector2i(x, y), 0, Vector2i(tile_x, tile_y))

      # 放置单个装饰（B 组第 5 列第 3 行的桌子）
      decor.set_cell(Vector2i(10, 10), 0, Vector2i(5, 3))

      # 获取 tile 信息
      var cell: Vector2i = ground.get_cell_atlas_coords(Vector2i(5, 5))
      print("(5,5) 的 tile: ", cell)

      # 删除 tile
      decor.erase_cell(Vector2i(10, 10))

方式 C：代码中动态加载 .tres

  var tileset: TileSet = load("res://object/outside_ground.tres") as TileSet
  $GroundLayer.tile_set = tileset

                └── DecorLayer（建筑、树木、装饰上层，y_sort=true）

六、关键 API 速查

═══════════════════════════════════════════════════════════

TileMapLayer:
  set_cell(pos, source_id, atlas_coords)    放置 tile
  erase_cell(pos)                            删除 tile
  get_cell_atlas_coords(pos) → Vector2i     获取 tile 坐标
  get_cell_source_id(pos) → int             获取 source ID
  get_used_cells() → Array[Vector2i]        获取所有已放置的 tile
  clear()                                    清空整个图层
  tile_set                                   当前使用的 TileSet

TileSet:
  tile_size                                  tile 尺寸（Vector2i）
  get_source(id) → TileSetSource            获取图块源
  add_source(source) → int                  添加图块源

TileSetAtlasSource:
  texture                                    源纹理
  texture_region_size                        每个 tile 的尺寸
  create_tile(atlas_coords)                  创建 tile
  has_tile(atlas_coords) → bool             检查 tile 是否存在
  get_tiles_count() → int                   tile 总数
  get_tile_id(atlas_coords) → int          获取 tile ID

七、常见问题

═══════════════════════════════════════════════════════════

Q: 图块看上去太小/太大？
A: TileMapLayer 的 tile 尺寸由 TileSet.tile_size 决定（默认 32×32）。
   检查 TileSet → tile_size 是否为 Vector2i(32, 32)。

Q: 装饰层的图块遮挡顺序不对？
A: 上层 TileMapLayer 需要开启 y_sort_enabled = true。
   角色也应在同一排序层级。

Q: 已经画好的图块保存为 .tres 后，画的图还在吗？
A: .tres 只保存 TileSet 定义（图块模板），不保存地图数据。
   地图数据保存在场景的 .tscn 文件中（TileMapLayer 的 cell 数据）。

Q: 如何导出/导入整张地图？
A: Godot 没有内置地图导出。可以用脚本遍历 get_used_cells()
   然后序列化为 JSON/自定义格式。或者直接复制场景文件中的 cell 数据。

Q: A1~A4 自动图块怎么高效配置 Terrain？
A: 手动为每个 autotile 块设置 bitmask 工作量大。建议：
   1. 先只用 A5 + B~E 的普通图块做原型
   2. 确定要用的地形后再配置 terrain
   3. 后续可写脚本自动映射 VX Ace autotile 布局 → Godot bitmask
