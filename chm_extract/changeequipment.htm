[Change Equipment]

 

Function

·Changes an actor's equipment.

 

Settings

 

·Under [Actor], specify the actor whose equipment should be changed.

Entire Party

All the members of the party at the time the command is carried out will be the targets of this command.

Fixed

A particular actor will be the target. Choose the actor from the dropdown menu.

Variable

The actor with the same number as the value stored in the given variable will be the target.
For example, if variable no. 2 is specified which contains “5” at the time the command is processed, actor no. 5 will become the target of this command.

Choose the variable to use from the [Variable] window which can be opened by clicking the [...] button.

 

·Under [Operation], choose whether to change or remove equipment.

Change

Removes the current item and equips a new item.

Remove

Removes the current item.

 

 

·If [Change equipment] was specified under [Operation], choose one of the following methods to specify the new equipment under [Item to equip].

Fixed

Equips a specific item. The item can be selected from the dropdown menu.

Variable

Equips the item with the same number as the value stored in the given variable.
For example, if variable no. 2 is specified which contains “5” at the time the command is processed, skill no. 5 will be learned (or forgotten).

Choose the variable to use from the [Variable] window which can be opened by clicking the [...] button.

 

 

·If [Remove Type] was specified under [Operation], choose the body part to unequip under [Part to remove]

All

Removes all equipment.

Weapon

Removes the equipped weapon.

Shield

Removes the equipped shield.

Armor

Removes the equipped armor.

Head

Removes the equipped helm.

Accessory

Removes the equipped accessory.

 

[Notes]

·If the item to be equipped is not currently in the player's possession, it will be added automatically.
