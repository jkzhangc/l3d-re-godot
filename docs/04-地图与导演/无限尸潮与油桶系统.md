# 无限尸潮与油桶系统（2026-11-21）

本页记录第三战役（死亡岛）用到的四个新玩法件：无限尸潮节点、油桶搬运、油桶容器、撤离到齐判定；以及同一批 UI 统一改动。

## 一、无限尸潮 · `InfiniteHordeMachine`

| 项 | 内容 |
|---|---|
| 脚本 | `script/director/infinite_horde_machine.gd` |
| 场景 | `object/infinite_horde_machine.tscn` |
| 摆放 | 直接放进地图场景；载入后**自动**进入预备倒计时（无需交互） |
| 联机 | Host 权威刷怪；Client 只同步倒计时与强度，不本地刷怪 |

### 参数

| 分组 | 字段 | 说明 |
|---|---|---|
| 启动 | `auto_start` | 默认 true，载入即开始预备 |
| 启动 | `prepare_duration` | 预备秒数（默认 30） |
| 启动 | `alert_lead_time` | 开刷前多少秒播「即将开始」音（默认 2） |
| 启动 | `prepare_sound` / `alert_sound` | 建议分别配 `sound/フィナーレ開幕.ogg`、`sound/ラッシュ開始.ogg`（与防守战同款） |
| 启动 | `suspend_director` | 开刷后挂起常规导演编排（默认 true，避免普通尸潮打架） |
| 刷怪 | `spawn_per_wave` / `spawn_interval` | 每批数量 / 批间隔；人数倍率与防守战同一套 |
| 刷怪 | `max_active` | 场上存活上限（0 = 不限） |
| 刷怪 | `horde_berserk` | 是否让丧尸切狂暴形态（默认 true；与难度附加参数「尸潮狂暴」取与） |
| 刷怪点 | `use_spawn_points` | 默认 true；地图里摆 `HoldoutSpawnPoint` 就按点位**轮转均分**出兵 |
| 强度 | `count_multiplier` / `interval_multiplier` | 供油桶容器提升；`set_intensity()` 可运行时改 |

- **默认不播尸潮 BGM**：节点本身没有音乐字段；需要 BGM 时由油桶容器或外部脚本播放。
- **开刷即进入尸潮窗口（2026-11-22）**：倒计时归零时调用
  `Director.set_external_horde_window(true, horde_berserk)` ——
  - 新刷的丧尸走 `spawn_enemy` 的尸潮分支：**直接锁定最近玩家**（Idle → Discover → Chase），不再依赖视野发现；
  - 场上已有丧尸补锁一次（不会重复接管已被防守战锁定/豁免的敌人）；
  - `horde_berserk` ∧ 难度「尸潮狂暴」为真时切クリムゾンヘッド形态（变体必须配 `rage_texture`，否则 `set_rage` no-op）；
  - 节点释放/换图时关闭窗口，恢复进入前的状态（不影响同时进行中的常规尸潮）。
  > ⚠ 只调 `spawn_horde_nodes()` 而不开窗口，丧尸会站着不追人 —— 这是 2026-11-22 用户实测的 bug 根因。
- **固定刷怪点（2026-11-22）**：地图里放 `HoldoutSpawnPoint` 后，每批敌人走
  `Director.spawn_horde_nodes_at_positions()`，与防守战**同一套点位协议** ——
  子树优先 / 全图兜底收集、玩家画面内屏蔽（`allow_in_view` 可跳过）、落点可站性校验、
  JUMP / DROP 出生演出全部照常生效。批次序号递增实现轮转，不会总从同一端出兵。
  一个点位都没摆（或 `use_spawn_points = false`）则沿用 `Director.spawn_horde_nodes()` 的屏幕外刷法。
- 点位是静态地图资产：开刷时收集一次并缓存，运行期不再扫描。
- 收场：换图 / 节点释放 —— 无限模式没有结束条件。

## 二、油桶搬运 · `OilBarrel`

| 项 | 内容 |
|---|---|
| 脚本 | `script/oil_barrel.gd` |
| 场景 | `object/oil_barrel.tscn` |
| 拾取 | 靠近按功能键(D)；`require_function_key=false` 可改自动拾取 |
| 持桶 | `PlayerState.carried_oil_barrel = true`；强制切 Idle、清空开火缓冲 |
| 限制 | 持桶时不能开火 / 举枪 / 投掷；右下角提示「D 放下油桶」 |
| 放下 | 再按 D → 在玩家脚下 18px 处生成新油桶（联机由 Host 落地） |
| 联机 | 拾取走 NetworkWorld 掉落物事务（快照 `pickup_kind = "oil"`）；放下走 `oil_barrel_drop_request` |

> 贴图没有内置素材：地图作者在 `texture` 里指定（支持 VX 行走图多角色表，`char_index` / `direction`）。
> 未指定时节点不可见但仍可交互 —— 正式摆放前务必配图。

## 三、油桶容器 · `OilBarrelContainer`

| 项 | 内容 |
|---|---|
| 脚本 | `script/director/oil_barrel_container.gd` |
| 场景 | `object/oil_barrel_container.tscn` |
| 需求 | `required_count`（默认 3） |
| 交互 | 靠近显示「需要油桶 x/3」；持桶时按 D 交付 |
| 装满 | 切换 `filled_texture` / `filled_char_index`，播 `horde_music`，把无限尸潮提升为 `boost_count_multiplier=1.5`、`boost_interval_multiplier=0.7` |
| 联机 | Host 校验「距离 ≤120 + 确实持桶」后记账；计数/装满状态广播给全体 |

- 装满 BGM 用容器上的 `horde_music` 固定曲目（`loop` 可配）；留空则不播。
- 提升只作用于场景里 `infinite_horde_machine` 组的节点；可以放多个容器叠加更高强度。

## 四、撤离前「存活玩家到齐」

- 共用工具：`script/director/evac_gate.gd`（只统计 `is_alive()` 的玩家）。
- `FinaleTrigger`：联机时所有存活玩家都要进入 `gather_radius`（默认 96）才能按确定键；
  标签显示「进入结局（等待队友 n/m）」。
- `HoldoutMachine`：`start_finale_ending()` / `start_ending_from_peer()` 同样校验；
  防守战打完后的终章交互也会守这道门。
- Client 请求进 ED 时会把触发点与半径一起发给 Host（`holdout_ending_request(center, radius)`），
  Host 按触发点而不是机器位置校验。
- 倒地/死亡玩家不阻塞（2026-11-21 用户确认）。

## 五、同批 UI 统一

- 成就弹窗 / 成就一览改用 RM 窗口皮：`script/ui/rm_window.gd`（`Window background color.png` + 20px 九宫格 `Window frame.png`），与安全屋台词框、操作说明、战役选择一致。
- 标题画面设置新增「智能提示」，与游戏内设置共用 `Global.show_action_hints`（持久化到 config）。

## 六、联机协议（新增）

| RPC / 信号 | 方向 | 用途 |
|---|---|---|
| `infinite_horde_state(phase, remaining)` | Host → Client | 无限尸潮倒计时（0.5s，unreliable） |
| `infinite_horde_intensity(count, interval)` | Host → Client | 强度变化（reliable） |
| `oil_barrel_drop_request(position)` | Client → Host | 请求放下油桶 |
| `oil_container_deposit_request(path)` | Client → Host | 请求交付油桶 |
| `oil_container_state(path, count, filled)` | Host → Client | 容器计数 / 装满 |
| `holdout_ending_request(center, radius)` | Client → Host | 进 ED 请求（带撤离判定中心） |

## 七、验证
