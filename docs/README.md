## 维护规则

1. 新方案、分析、指南和开发记录按主题写入本目录，不在项目根散放；新文档同时加入本索引。
2. 根目录仅保留 README、AGENTS、CLAUDE、MEMORY 四个精简发现入口，正文不要重复维护。
3. 文档中的 `script/`、`scene/`、`tools/` 等工程路径默认相对于项目根；可点击链接则按所在文档的相对路径编写。
4. 本次迁移保留文件名与内容；只修复链接、导航和文档读取路径。未提交的游戏资源与网络实验代码不随本次整理修改。
5. 迁移备份和逐文件原始 SHA-256 清单位于 `.workbuddy/backups/docs-reorg-20261121T054929Z/`；这是可回溯项目数据，不是应随手清理的缓存。
