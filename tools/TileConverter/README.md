# RPG Maker 2000/2003 → MV/MZ 素材批量转换器

> 工具编写：茶A_tea

将 RPG Maker 2000/2003 的素材转换为 RPG Maker MV/MZ 格式的 Windows 桌面工具。
转换逻辑 1:1 移植自 くらむぼん（krmbn0576）的网页转换器：
https://krmbn0576.github.io/rpgmakermv/converter.html

## 使用方法

1. 双击 `dist\MV素材批量转换器.exe` 启动（无需安装 Python）
2. 点击 **添加文件…** 或 **添加文件夹…** 选择素材（支持 png / bmp / gif / webp）
3. 软件自动按尺寸识别类型：
   - **行走图** 288×256（角色芯片）
   - **头像** 192×192（脸图）
   - **地图图块** 480×256（图块集）
4. 设置导出文件夹，点击 **开始批量转换**
5. 结果按类型自动分目录导出：
   - `characters/` → 放入 MV/MZ 工程 `img/characters/`
   - `faces/` → 放入 `img/faces/`
   - `tilesets/` → 放入 `img/tilesets/`（A1/A2/A5/B 四张图）

## 转换设置说明

**行走图**
- 放大方式：邻近缩放（点阵、不失真，默认）/ xBR 平滑放大（移植自网页的 xBR 算法）
- 放大倍率：1 / 2（推荐，接近 MV 角色大小）/ 3 倍
- 自动完成：透明色清除、帧重排（RPG2000 的行序 上右下左 → MV 的 下左右上）、
  24×32 帧 → MV 的 32×32 格式（水平居中 ±4px）

**头像**：固定 3 倍，可选邻近缩放（默认）或平滑放大

**地图图块**：固定邻近缩放，倍率 1 / 2 / 3（推荐 3 倍，与 MV 地图同尺寸），
自动拆分为 MV 的 A1 水图块 / A2 自动图块 / A5 下层图块 / B 上层图块四张图。
- 附加：输出自动图块全部图案（C/D/E 三张）
- 附加：输出动画图块（含第 4 帧，文件名前加 `!$` 放入 characters 文件夹使用）

## 注意事项（与原网页一致的限制）

- 仅接受三种标准尺寸；其他尺寸会自动跳过并在列表/日志中标注
- A2 自动图块采用"角优先"选别，部分自动图块之间的接续可能不自然
- A1 海洋图块与深海图块的连接、瀑布第 4 帧等存在与网页版相同的固有损失
- B 图块左上角第一个 tile 是"空图块"（透明键来源），为正常现象
