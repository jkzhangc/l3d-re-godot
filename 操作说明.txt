========================================================
  のび太的求生之路 〜LEFT 3 DEAD〜 操作说明
========================================================

【移动】
[↑↓←→] 移动 / 界面光标
[Ctrl] 按住 = 慢走；松开 = 奔跑
· 按住 Ctrl 期间数字键 1~5 不可用，松开后再按即可

【基本操作】
[Z] 攻击 / 确认
[X 或 Esc] 取消 / 返回
[P 或 Esc] 打开主菜单（物品 / 装备 / 存档 / 退出）
[D] 互动：拾取 / 替换武器 / 医疗箱 / 防守战机器
[Shift] 举起 / 放下手中武器
· 举起枪械后可以固定朝向：
  切换式 = 按一下锁定、再按一下解除；按住式 = 按住锁定、松开解除
  两种模式可在「设置」里切换（标题菜单与暂停菜单都设有入口）

【武器与物品】
[1] 举起 / 切换主武器（步枪、霰弹枪 等）
[2] 举起 / 切换副武器（手枪、近战武器 等）
[3] 使用治疗品（急救喷雾）
[4] 使用辅助品
[5] 举起 / 放下投掷物（手雷、燃烧瓶）
[A] 装填弹药
[E] 丢弃身上全部武器（主武器与副武器一起丢在脚下，方便换枪或减重跑图）
· 掉落物叠在一起时只会拾取最近的一件；走开再回来可选下一件
· 联机时治疗品与急救喷雾都是每人一份，各用各的

【投掷物：手雷 / 燃烧瓶】
[5] 举起 / 放下投掷物（举起后显示投掷轨迹线）
[Z] 点按 = 直接扔出；按住 = 锁定方向瞄准，松开扔出
[A / S] 调整投掷距离（加 / 减格）
[X 或 Esc] 瞄准时取消

【见切与反击】
· 按 Z 攻击后会登记 0.3 秒的见切窗口（与攻击共用同一个键）
· 见切窗口内被敌人击中 = 见切成功：不受伤害，并自动发动角色专属反击
· 两次见切输入之间需间隔 0.7 秒，狂按无效

【特殊动作】
[C] SA 技能（角色专属，按下即发动；各角色的效果见角色选择界面）
[空格] 覚醒「集中射撃」（觉醒·集中射击）：举起枪械后按下，消耗 TP
· 觉醒期间枪械威力提升、子弹即死（Boss 免疫即死，但仍受更高伤害）
[S] 推开眼前的感染者
[Q] 切换操作角色（联机模式不可用）
[Ctrl+1/2/3] 直接切到第 1/2/3 名队员（同上，仅单机可用）

【状态：过热（Heat）】
· 被特感的特殊攻击命中后会进入过热状态
· 过热期间无法见切、无法切换角色 —— 请先等它自然解除

【进阶技巧】
· 霰弹枪开火后的泵动（收势）动画可以用 [S] 推开取消
  被围住时用连射换掉动画时间，是故意保留的高速清怪技巧
· 见切成功后可以立刻再攻击，续上下一次见切窗口

【生存须知】
· HP 归零时，身上有急救喷雾会自动使用并满血复活
· 身上没有喷雾时会自动切换到其他存活队员；全队倒下即战役失败
· 按 D 使用医疗箱：全队回满血并复活倒下的队员
  联机时为每人各一次、且只能治疗自己；所有人都用过之后箱子才会消失
· 尸潮来临时 BGM 会变化 —— 听到音乐变了就快找掩体！
· 狂暴化的红衣丧尸跑得快、伤害高，奔跑约 10 秒后会力竭倒地
  抓住它趴地的时机反击

【安全屋台词】
· 进入安全屋时会显示当前角色的专属台词（带头像与名字）
· 台词显示期间无法移动；按 [Z] 看下一段，看完再按 [Z] 关闭
[X] 可以在任意时刻直接跳过

【手机版触摸操作（仅手机版显示）】
· 屏幕左下：虚拟摇杆（移动）
· 屏幕右下 · 动作区：攻击 / 互动 / 装填 / 推击 / SA
· 屏幕右下 · 物品区：主武器 / 治疗品 / 辅助品 / 投掷物
· 屏幕右下 · 系统区：菜单 / 取消 / 丢弃武器 / 切换角色
· 触摸按钮与键盘按键功能完全一致，只是更贴合手机操作
