========================================================
  のび太的求生之路 〜LEFT 3 DEAD〜 操作说明
========================================================

【移动】
[↑↓←→] 移动 / 选择菜单
@pc [Ctrl] 按住 = 慢走；松开 = 奔跑
@pc · 按住 Ctrl 的时候，数字键 1~5 会暂时失效，松开再按就好

【基本操作】
[Z] 攻击 / 确认
[X 或 Esc] 取消 / 返回
[P 或 Esc] 打开主菜单（物品 / 装备 / 存档 / 退出）
[D] 互动：捡东西 / 换武器 / 用医疗箱 / 启动防守战机器
@pc [Shift] 举起 / 放下手里的武器

【举枪时固定朝向】
· 举起枪之后可以把朝向锁住，方便一直对着同一个方向打
· 在「设置」里选锁定方式：
  按一下锁定、再按一下解锁 ／ 按住锁定、松开解锁

【武器与物品】
[1] 换上主武器（步枪、霰弹枪 等）
[2] 换上副武器（手枪、近战武器 等）
[3] 使用治疗品（急救喷雾）
[4] 使用辅助品
[5] 举起 / 放下投掷物（手雷、燃烧瓶）
[A] 装填弹药
[E] 把手上的武器全部丢在地上（想换枪、或想跑快一点时用）
· 地上的东西叠在一起时只会捡起最近的一件，走开再回来可以捡下一件
· 联机时急救喷雾和药品都是每人一份，各用各的

【扔手雷 / 燃烧瓶】
[5] 举起投掷物（举起后会显示扔出去会落在哪里）
[Z] 轻按 = 直接扔；按住 = 定住方向瞄准，松开再扔
[A / S] 把落点调远 / 调近
[X 或 Esc] 取消

【见切】
· 敌人打中你的那一瞬间，只要你正好按下攻击键，这次攻击就会失效，
  并自动反击回去
· 时机很宽松：从敌人快要打到你之前的 0.3 秒内按下就能见切
· 见切成功后要隔 0.7 秒才能再来一次，所以一直狂按是没用的
· 身上有「过热」的时候不能见切（见下方说明）

【角色特技（SA）】
[C] 使用角色的特殊技 SA
· 每个角色的 SA 都不一样，可在角色选择界面查看

【觉醒】
· 觉醒是每个角色独有的看家本领 —— 目前只有一部分角色有
· 发动觉醒要消耗 TP：屏幕左上角的第三根槽（血量、弹药之后的那个）
· 发动后 TP 会慢慢减少，减到 0 就自动结束

【大雄的觉醒：集中射击】
@pc · 先举起枪，再按 [空格] 发动
@phone · 手机版暂时没有发动觉醒的按钮，这个能力在手机上还不能用
· 发动期间打出的子弹威力更大，打中普通丧尸直接击杀
· 打 Boss 杀不死，但伤害更高
· TP 用完、死亡或换人时自动解除

【其它操作】
[S] 推开挡在面前的丧尸
[Q] 换人操作（联机模式不可用）
@pc [Ctrl+1/2/3] 直接换成第 1/2/3 名队员（同上，仅单机可用）
@pc [F1] 查看更新日志（第一次进游戏会自动显示一次）
@phone · 查看更新日志：标题画面右上角的「更新日志」

【身上的「过热」状态】
· 被强力丧尸的特殊攻击打中之后，身上会冒火，这就是「过热」
· 过热期间不能见切、也不能换人 —— 等火自己灭掉就好

【实用技巧】
· 霰弹枪每打完一发都要拉一次枪机，这个动作可以用 [S] 推开取消
  被包围时能明显打得更快，这是故意保留的技巧
· 见切成功会把面前的丧尸推开一段距离，趁它后退时换弹或走位都行
· 打丧尸的头部伤害更高，但命中范围也小，站远了更稳

【生存常识】
· 血量归零时，如果身上带着急救喷雾，会自动使用并把血回满
· 身上没有喷雾时会自动换成其他还活着的队员；全队都倒下就战役失败
· 按 [D] 使用医疗箱：全队回满血，还能把倒下的队员救起来
· 丧尸潮来的时候音乐会变 —— 听到音乐变了就赶紧找地方躲
· 穿红衣服的狂暴丧尸跑得快、打得也疼，追你大约 10 秒后会累趴下
  它趴着的时候就是见切的最好时机

【安全屋里的对话】
· 进入安全屋时会自动出现角色的对话（带角色头像和名字）
· 对话出现时不能移动；按 [Z] 看下一句，看完再按 [Z] 关掉
· 按 [X] 可以直接跳过

@phone 【手机版触摸操作】
@phone · 屏幕左下：摇杆（移动；在菜单里用来上下选择）
@phone · 屏幕右下分三块：
@phone   · 动作区：攻击 / 功能 / 装填 / 推击 / SA
@phone   · 物品区：主武器 / 副武器 / 治疗品 / 辅助品 / 投掷物
@phone   · 系统区：菜单 / 取消 / 丢武器 / 换人
@phone · 按钮和键盘按键功能完全一样
@phone · 在菜单界面只显示「摇杆 / 确定 / 取消」三个按钮，战斗按钮只在关卡里出现，不会挡住菜单
